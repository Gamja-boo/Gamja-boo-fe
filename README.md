# Gamja-boo

### 서비스 소개

**감자부**는 사용자가 한 달 동안 절약한 금액을 포인트로 환산해 제공하고, 이 포인트로 게임 내 아이템을 구매하여 캐릭터를 꾸밀 수 있는 게임형 가계부 앱입니다. <br>
반복적인 기록만으로 금방 지치는 기존 가계부 방식에서 벗어나, 절약이 곧 캐릭터 성장으로 이어지는 구조를 통해 사용자의 지속적인 가계부 사용을 자연스럽게 유도합니다.
